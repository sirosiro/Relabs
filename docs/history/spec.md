3Dモデリングツール 仕様書（草案）
1. システム概要
複数の立方体を配置・編集できる、面ベースの3Dモデリングツール。
開発言語: Python
主要機能: 3Dビュー（回転可能）、面選択、数値入力（絶対・相対）、リアルタイム同期
2. 空間・座標系の定義
座標軸:
X軸: 幅 (Width)
Y軸: 奥行き (Depth)
Z軸: 高さ (Height)
頂点定義順（巻順）: 左下 → 右下 → 右上 → 左上の順（反時計回り）。これはOpenGL等の標準的な法線計算とも相性が良い。
3. GUI構成
画面を左右のペインに分割する。
セクション
機能概要
左側：3D表示エリア
OpenGL等による描画。マウスのドラッグでカメラが上下左右に回転（軌道制御）。面をクリックで選択。
右側：コントロールパネル
選択された面の座標（4頂点分）を表示・編集するテキストボックス。
入力モード切替
「絶対値モード」と「相対値モード（基準点からのオフセット）」をトグルで切り替え。
4. 主要データ構造
面を独立したエンティティとして管理し、それらを束ねて「物体（立方体）」とする。
class Face:
    def __init__(self, vertices):
        # vertices: [v1, v2, v3, v4] 各点(x, y, z)
        self.vertices = vertices 
        self.parent_id = None # どの立方体に属するか

5. 詳細仕様・アルゴリズム
A. 面の選択（ピッキング）
マウスで3D空間をクリックした際、カメラの座標からクリック位置を通る光線（レイ）を飛ばし、最初に交差した「面」を特定する。
同期処理: 選択された面の4頂点座標を即座に右側のテキストボックスに反映させる。
B. 座標入力モード
絶対値モード: 空間全体の原点 を基準とした座標を表示。
相対値モード: 立方体の中心点、あるいは特定の「基準点」を と見なした差分を表示。
C. カメラ制御
回転: ピッチ（上下）とヨー（左右）の角度を持ち、マウスの移動量に応じて更新する。
--------------------------------------------------------------------------------
凄腕エンジニアからのアドバイス
ライブラリ選定: 手軽に作るなら PySide6 (Qt) の QOpenGLWidget を使うのが一番堅牢だ。数値入力と描画の同期が楽になる。
法線の考慮: 「左下→右下→右上→左上」という順序を厳守することで、ポリゴンの表裏（カリング）を正確に制御できる。これは将来的にライティング（影）を入れる際にも重要だ。
衝突判定: 「どの面を触ったか」の判定には、各面を2つの三角形に分割して Möller–Trumbore 交差アルゴリズム を使うのが定石だな。

3Dモデリングツール 仕様書 (Draft)
1. システム概要
Pythonで構築する、立方体を基本単位とした面ベースの3Dモデリングツール。 直感的な3Dビュー操作と、数値入力による精密な座標制御を両立させる。
2. 空間・座標系の定義
座標軸の役割
X軸: 幅 (Width)
Y軸: 奥行き (Depth)
Z軸: 高さ (Height)
頂点定義順（巻順）
1つの面は4つの頂点で構成される。
左下 → 右下 → 右上 → 左上 の順で定義する（反時計回り）。
この順序により、面の表裏（法線ベクトル）を決定する。
3. GUI構成
画面を左右のペインに分割して構成する。
3.1 左側：3D表示ペイン
描画内容: 3D空間内に配置された全ての立方体を表示。
カメラ制御: マウスドラッグにより、視点を上下左右に回転（軌道回転）可能。
面選択: マウスによる面のクリックで対象を選択。選択された面はハイライト表示される。
3.2 右側：コントロールペイン
数値編集: 選択された面の4頂点（計12個の数値）を入力するテキストボックス。
入力モード切替:
絶対値モード: 空間原点 からの座標値を編集。
相対値モード: ユーザーが指定した基準点、または物体の中心からのオフセット値を編集。
同期機能: GUIでの面選択時、即座に該当座標をテキストボックスに反映。テキストボックス更新時は3D表示を即時更新。
4. エクスポート機能 (XML)
モデリングしたデータをXML形式で出力する。
4.1 出力範囲の選択
エクスポート実行時に、以下のいずれかを選択可能とする。
全モデル（All Models）: 空間内に配置されている全ての立方体と、それを構成する全ての面情報を出力。
選択中の面（Selected Face Only）: 現在編集対象（セレクト）となっている特定の1面のみを出力。
4.2 XML構造案
<ModelingData>
    <SceneInfo>
        <ExportDate>2026-01-31T12:00:00</ExportDate>
    </SceneInfo>
    <Models>
        <Model id="cube_001">
            <Faces>
                <Face id="face_1">
                    <Vertices>
                        <Vertex index="0" x="0" y="0" z="0" /> <Vertex index="1" x="1" y="0" z="0" /> <Vertex index="2" x="1" y="0" z="1" /> <Vertex index="3" x="0" y="0" z="1" /> </Vertices>
                </Face>
                </Faces>
        </Model>
    </Models>
</ModelingData>

5. 技術選定（推奨）
GUIフレームワーク: PySide6 (Qt for Python)
QOpenGLWidget を用いることで、複雑なUIと3D描画の統合が容易。
3D描画ライブラリ: PyOpenGL または ModernGL
XML操作: Python標準の xml.etree.ElementTree または lxml

エンジニアからの実装への助言
XML設計: Vertex 要素に index 属性を持たせることで、仕様である「左下から順」という制約をデータレベルで保証できる。
相対値モードの計算: 内部データは常に「絶対値」で保持し、UI表示の瞬間のみ計算して出し分けるのが、データ整合性を保つコツだ。

1. 概念・構造重視（硬派なエンジニア向け）
Facets (ファセッツ) 「（物体の）面」を意味する言葉。面単位でモデリングするという仕様をそのまま表しており、音もスマートだ。
AxisFlow (アクシス・フロー) XYZ軸を意識し、絶対・相対座標を自在に行き来する操作性を表現。
VertexOrder (バーテックス・オーダー) 仕様で強調した「左下からの巻順」をリスペクトした名前。データ構造を重視する姿勢が伝わる。
2. 直感的・ツール名らしいもの（親しみやすさ重視）
CubeCraft Python (CCP) 立方体を組み合わせて作る楽しさを表現。Python製であることをアピールできる。
FaceEdit 3D 「面を編集する」という目的が1秒で伝わる。
XYZ-Molder (XYZモルダー) 座標をこねて形を作る、粘土細工（Molding）のような感覚。
3. 短く、CLIツールやパッケージ風
f3d (Face 3D) 短い名前はコマンドラインやディレクトリ名にした時に映える。
Relabs (リラブス) Relative（相対）と Absolute（絶対）を組み合わせた造語。このツールの最大の特徴である「モード切替」を象徴している。

私のイチオシ
個人的には Relabs (リラブス) を推したい。 「絶対値と相対値を使い分ける」という仕様は、単純なビジュアルモデラーではなく「座標を正確に制御したいエンジニアのためのツール」であることを示しているからだ。
